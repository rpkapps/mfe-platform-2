title: Create an MFE
description: Scaffold a complete, runnable micro-frontend with one command, then run it in the local shell harness.
---

<Steps>

<Step>Scaffold the project</Step>

```bash
npx @platform/cli create my-mfe
```

The command asks for nothing it can infer. It creates a TanStack Router project with the platform integration, Tecton UI, Tailwind CSS with selector isolation, tests, lint configuration and the AI guidance files. Pass `--react 18` for a React 18 remote, `--no-tecton` to skip the UI library, or `--widgets-only` for a widget library without routes.

<Step>Install and start</Step>

```bash
cd my-mfe
pnpm install
pnpm dev
```

`pnpm dev` runs `platform dev`: a Vite dev server for the remote plus the **local shell harness** at `http://localhost:4200/__platform/harness/`. The harness is a self-contained shell with a realistic user, permission groups, tenant/project/job context, a command palette, settings, widget slots, overlays and failure toggles. Your MFE hot-reloads inside it.

<Step>Build</Step>

```bash
pnpm build
```

`platform build` runs the Vite production build and writes `dist/`: the remote entry (`remoteEntry.js`), code-split route chunks, scoped CSS and `platform-manifest.json`. Deploy `dist/` to any static origin; the shell loads it from the manifest URL.

</Steps>

## The bootstrap file

`src/mfe.tsx` is the only platform-specific file you need to know about. It default-exports a `RemoteDefinition`; the generated entry (`.platform/entry.tsx`) wraps it with `withTecton` and exposes it to the host.

```tsx title="src/mfe.tsx"
import { createMfe } from "@platform/react"

import { routeTree } from "./routeTree.gen"
import { assetCard } from "./widgets/asset-card"

export default createMfe({
  routeTree,
  widgets: { assetCard },
})
```

`mfeId` is inferred from the package name (`@acme/my-mfe` → `my-mfe`) and persisted in `.platform/identity.json`, so renaming the package later does not change storage keys or command ids. See [Manifests](/docs/manifests#mfe-id).

## Scripts

| Script          | Runs                                                                            |
| --------------- | ------------------------------------------------------------------------------- |
| `pnpm dev`      | `platform dev` — Vite dev server + harness with HMR                             |
| `pnpm build`    | `platform build` — production remote with manifest                              |
| `pnpm manifest` | `platform manifest` — print the manifest that a build would emit                |
| `pnpm validate` | `platform validate` — validate `dist/platform-manifest.json` against the schema |
| `pnpm lint`     | `platform lint` — the shareable ESLint config                                   |
| `pnpm test`     | `platform test` — Vitest (unit + integration)                                   |
