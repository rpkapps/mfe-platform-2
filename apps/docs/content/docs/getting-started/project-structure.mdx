---
title: Project structure
description: Predictable file locations and one canonical pattern for every task, so humans and coding agents always know where things go.
---

The scaffold has exactly one place for each concern. Add features by adding files in those places; do not introduce a second bootstrap, a second router, a second registration style or a second storage helper.

## File locations

| Concern             | Location                                     | Canonical API                                                                                                 |
| ------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Bootstrap           | `src/mfe.tsx`                                | `createMfe({ routeTree, widgets, registrations })` (default export)                                           |
| Routes              | `src/routes/**`                              | `createFileRoute` / `createRootRouteWithContext<MfeRouterContext>`                                            |
| Route tree          | `src/routeTree.gen.ts`                       | generated; never edited                                                                                       |
| Widgets             | `src/widgets/*.tsx`                          | components; `createWidget({ component, propsSchema })` in `src/mfe.tsx`                                       |
| Commands            | next to the feature (`src/routes/index.tsx`) | `useRegisterCommand` in the component that owns the feature                                                   |
| Settings            | `src/routes/settings.tsx` (or a `use*` hook) | `useRegisterSettingsGroup`                                                                                    |
| Storage             | `src/lib/storage.ts`                         | `createPlatformStorage`                                                                                       |
| Data access         | `src/lib/api.ts`                             | `useRuntimeEnv().API_BASE_URL` / `context.platform.runtime.env`                                               |
| Help, release notes | `src/mfe.tsx` (`registrations`)              | static entries; `useRegisterHelp` / `useRegisterReleaseNotes` for state-dependent ones                        |
| Typing              | `src/platform.d.ts`                          | `Register` augmentations for `@platform/mfe-react` (env, feature flags) and `@tanstack/react-router` (router) |
| Configuration       | `mfe.config.ts`                              | `defineMfeConfig`                                                                                             |
| Identity            | `.platform/identity.json`                    | generated once; committed                                                                                     |
| Styles              | `src/styles.css`                             | imported by `src/mfe.tsx`; scoped under `[data-mfe]` at build time                                            |
| Tests               | `src/__tests__/*.test.tsx`                   | `renderMfe` and `createTestBridge` from `@platform/mfe-react/testing`                                         |

## Bootstrap

```tsx title="src/mfe.tsx"
import { createMfe, createWidget } from "@platform/mfe-react"
import { z } from "zod"

import "./styles.css"
import { routeTree } from "./routeTree.gen"
import { WellSummary } from "./widgets/well-summary"

export default createMfe({
  routeTree,
  widgets: {
    "well-summary": createWidget({
      component: WellSummary,
      propsSchema: z.object({ wellId: z.string() }),
    }),
  },
  // errorComponent, pendingComponent, notFoundComponent: optional, default to the platform boundaries
})
```

## Root route

The root route declares the platform context type and the breadcrumb root. Everything under it gets `context.platform` in `beforeLoad` and loaders.

```tsx title="src/routes/__root.tsx"
import { createRootRouteWithContext, Outlet } from "@tanstack/react-router"
import { MfeErrorBoundary, type MfeRouterContext } from "@platform/mfe-react"

export const Route = createRootRouteWithContext<MfeRouterContext>()({
  staticData: { breadcrumb: "My MFE" },
  component: () => (
    <MfeErrorBoundary>
      <Outlet />
    </MfeErrorBoundary>
  ),
})
```

## A route

```tsx title="src/routes/wells/$wellId.tsx"
import { createFileRoute, redirect } from "@tanstack/react-router"

import { fetchAsset } from "@/lib/api"

export const Route = createFileRoute("/wells/$wellId")({
  staticData: { breadcrumb: { fromLoader: "breadcrumb" }, permissionGroups: ["wells:read"] },
  beforeLoad: ({ context, params }) => {
    if (!context.platform.permissions.hasGroup("wells:read")) {
      throw redirect({ to: "/", search: { denied: params.wellId } })
    }
  },
  loader: async ({ context, params, abortController }) => {
    const span = context.platform.telemetry.span("well.load", { wellId: params.wellId })
    try {
      const well = await fetchWell(
        context.platform.runtime.env.API_BASE_URL,
        params.wellId,
        abortController.signal
      )
      span.end()
      return { well, breadcrumb: well.name }
    } catch (error) {
      span.fail(error)
      throw error
    }
  },
  component: AssetDetail,
})

function AssetDetail() {
  const { well } = Route.useLoaderData() // typed through the Register augmentation
  return <h2>{well.name}</h2>
}
```

## A command

```tsx title="src/routes/index.tsx"
import { useNotifications, useRegisterCommand } from "@platform/mfe-react"

function Dashboard() {
  const { notify } = useNotifications()
  useRegisterCommand({
    id: "say-hello", // local; the platform registers it as `<mfeId>:say-hello`
    label: "Say hello",
    group: "My MFE",
    keywords: ["greeting"],
    shortcut: "mod+shift+h",
    handler: () => notify({ title: "Hello", kind: "info" }),
  })
  return null
}
```

## A settings group

```tsx title="src/routes/settings.tsx"
import { useRegisterSettingsGroup } from "@platform/mfe-react"
import { z } from "zod"

function SettingsPage() {
  useRegisterSettingsGroup({
    key: "display",
    title: "Display",
    fields: {
      density: {
        defaultValue: "comfortable",
        schema: z.enum(["comfortable", "compact"]),
        options: [
          { value: "comfortable", label: "Comfortable" },
          { value: "compact", label: "Compact" },
        ],
      },
      showAbandoned: { defaultValue: true, description: "Include abandoned wells in lists" },
      pageSize: {
        defaultValue: 25,
        schema: z.number().int().min(5).max(200),
        min: 5,
        max: 200,
        step: 5,
      },
    },
  })
  return <p>The Display group is rendered by the shell settings host.</p>
}
```

## A storage store

```ts title="src/lib/storage.ts"
import { createPlatformStorage } from "@platform/mfe-react"
import { z } from "zod"

export const dashboardStorage = createPlatformStorage({
  scope: "local",
  key: "dashboard",
  schema: z.object({
    columns: z.array(z.string()),
    density: z.enum(["compact", "comfortable"]),
  }),
  defaults: { columns: ["name", "status"], density: "comfortable" },
  version: 2,
  // v1 stored a bare array of columns; invalid data without a migration resets to defaults.
  migrate: (stored) =>
    Array.isArray(stored)
      ? { columns: stored as string[], density: "comfortable" as const }
      : undefined,
})
```

## A widget

```tsx title="src/widgets/well-summary.tsx"
import { useNavigation, useMfeInstance, useRegisterCommand } from "@platform/mfe-react"

export function WellSummary({ wellId, compact }: { wellId: string; compact?: boolean }) {
  const navigation = useNavigation()
  const { routePrefix } = useMfeInstance()
  useRegisterCommand({
    id: "open-well", // widget commands are instance-scoped automatically
    label: `Open ${wellId}`,
    handler: () => navigation.navigate(`${routePrefix ?? ""}/wells/${wellId}`),
  })
  return <section data-well={wellId}>{compact ? wellId : `Well ${wellId}`}</section>
}
```

The widget is exposed in `src/mfe.tsx` under a kebab-case key (`"well-summary"`), which becomes its id.

## Conventions

- Local ids and keys (`say-hello`, `display`, `dashboard`) are kebab-case. The platform namespaces them with the `mfeId` and, for widgets, the `instanceId`.
- Hooks register from a component that lives as long as the feature; registration is removed on unmount. Groups that must be live whenever the MFE is mounted (the shell mounts settings owners headlessly) belong in the root layout.
- Never read `window.localStorage`, `import.meta.env` or `@module-federation/*` in MFE code. The [lint rules](/docs/linting) flag it.
- Generated files (`routeTree.gen.ts`, `.platform/*`, `dist/platform-manifest.json`) are inspectable but never edited.
