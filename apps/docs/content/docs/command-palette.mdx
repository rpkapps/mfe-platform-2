## What the shell searches

| Source                     | Entries                                                                            | Available before loading the remote?                                                    |
| -------------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| [Commands](/docs/commands) | label, description, keywords, group, shortcut                                      | static ones (`registrations.commands`, manifest) yes; hook-registered ones once mounted |
| MFE navigation metadata    | `navigation.title`, `keywords` from the manifest and route `staticData.navigation` | yes                                                                                     |
| Settings groups and fields | titles, labels, keywords ([Settings](/docs/settings))                              | groups yes (manifest); fields for framework-managed groups                              |
| Help entries               | title, description, keywords                                                       | static ones yes                                                                         |
| Release notes              | version, title, keywords                                                           | static ones yes                                                                         |
| Breadcrumbs                | current trail entries, when the host enables it                                    | active MFE only                                                                         |

Permission groups filter results: a command or route the user cannot use is not shown.

## Rendering

The palette is **the shell's own component**, not one the platform ships: a shell's design
system is not the platform's business. What the platform provides is the hard part behind it —
the search index, the command runner and the shortcut listener — and a reference implementation
to copy:

```ts
import {
  createCommandSearchIndex, // ranked, grouped search over every source in the table above
  SEARCH_GROUPS,
  runCommand, // the command state machine, abort support and telemetry
  commandHref,
  isCommandAvailable,
  installShortcutListener, // one listener, stays out of inputs (PlatformProvider installs it)
} from "@platform/host"
```

`apps/conformance-shell/src/components/palette.tsx` in the platform repository is 215 lines of
Tecton on top of those exports. Copy it and restyle it — that is the intended path, and it means
changing a button never needs a package release.

```tsx title="apps/shell/src/routes/__root.tsx"
import { CommandPalette } from "@/components"

;<CommandPalette
  hotkey="mod+k"
  placeholder="Search commands, pages, settings…"
  settingsPath="/settings"
  helpPath="/help"
  releaseNotesPath="/release-notes"
/>
```

The reference implementation's props: `hotkey` (default `mod+k`; `null` disables the shortcut), `placeholder`, `open` / `onOpenChange` for a controlled dialog, `settingsPath` (setting results navigate to `<settingsPath>?group=<key>&field=<key>`), `helpPath`, `releaseNotesPath` and `limit`. It is a Tecton command dialog over the host search index, grouped by source (`command`, `navigate`, `setting`, `help`, `release-note`, `breadcrumb`), with running, failed and done badges for async commands. Shortcuts are dispatched by the single keyboard listener `PlatformProvider` installs, whatever the palette looks like.

## Programmatic access

```ts
await host.commands.run("well-planner:slow-sync", { source: "api" }) // { qualifiedId, outcome, durationMs, error? }
host.commands.abort("well-planner:slow-sync")
host.commands.running() // qualified ids
host.registries.commands.list() // RegisteredCommand[]
host.registries.commands.conflicts() // { shortcut, holder, rejected }[]
```

## Not business data

The first release does not search business entities (wells, reports, users). Commands may implement their own pickers after being invoked (a "Go to well…" command that opens a Tecton `Combobox`), but the palette index stays limited to the sources above. This keeps the index static, permission-aware and fast, and avoids leaking data through metadata. General business-data search is listed under [Unsupported cases](/docs/unsupported-cases).
