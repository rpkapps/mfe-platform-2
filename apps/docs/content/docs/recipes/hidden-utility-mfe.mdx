---
title: Hidden utility MFE providing commands
description: A remote with no App Finder entry that contributes global commands, available before it is loaded.
---

```ts title="mfe.config.ts"
import { defineMfeConfig } from "@platform/vite/config"

export default defineMfeConfig({
  discoverable: false,
  navigation: { title: "Support tools", keywords: ["support", "diagnostics"] },
})
```

```tsx title="src/mfe.tsx"
import { createMfe } from "@platform/mfe-react"
import { routeTree } from "./routeTree.gen"

export default createMfe({
  routeTree, // /support-tools/diagnostics, /support-tools/export
  registrations: {
    // static: listed in the manifest and in the palette before the remote loads
    commands: [
      {
        id: "open-diagnostics",
        label: "Open diagnostics",
        route: "/diagnostics",
        keywords: ["debug", "logs"],
        group: "Support",
      },
      {
        id: "export-session",
        label: "Export session report",
        route: "/export",
        permissionGroups: ["support"],
      },
    ],
    help: [
      { id: "support-guide", title: "Support guide", href: "https://help.example.com/support" },
    ],
  },
})
```

Commands with handlers need the remote to be mounted. Register them from the root layout so they are live whenever the remote is mounted — including headless mounts:

```tsx title="src/routes/__root.tsx"
function RootLayout() {
  useRegisterCommand({
    id: "copy-session-id",
    label: "Copy session id",
    shortcut: "mod+shift+i",
    handler: async ({ platform }) => {
      await navigator.clipboard.writeText(platform.user?.sessionId ?? "")
    },
  })
  return <Outlet />
}
```

```tsx title="apps/shell/src/routes/__root.tsx"
{
  /* keeps the remote's hook registrations live on every page, without breadcrumbs or visible output */
}
;<MfeOutlet mfeId="support-tools" headless />
```

```text
PLATFORM_MFE_SUPPORT_TOOLS_PRELOAD=eager   # optional: evaluate the definition at startup
```

Result:

- The App Finder never shows _Support tools_.
- `Open diagnostics` and `Export session report` appear in the palette from the manifest (static, filtered by permission groups); running one loads the remote and navigates to `/support-tools/diagnostics`.
- With the headless outlet, `Copy session id` and its shortcut are live everywhere; the MFE router sees an inactive location and never touches the URL. This is how the conformance shell keeps settings owners registered on its settings page.
- Deep links to `/support-tools/*` work like any route.
