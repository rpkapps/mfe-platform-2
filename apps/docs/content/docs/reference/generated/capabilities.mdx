Capabilities are requested by a remote (inferred by `@platform/vite` from the SDK APIs it uses, adjustable with `capabilities: { add, remove }` in `mfe.config.ts`) and approved by the host. The approved set is exposed through the platform context (`usePlatform((p) => p.capabilities)`, `useCapability(id)`); calling an API whose capability is not approved fails with `CAPABILITY_UNAVAILABLE`. Implicit capabilities are granted to every remote. See [Platform context](/docs/platform-context#capabilities). Schema: [`/schemas/capabilities.json`](/schemas/capabilities.json).
