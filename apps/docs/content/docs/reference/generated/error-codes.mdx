## Codes

### MANIFEST_FETCH_FAILED

Check the manifest URL, the remote deployment and the allowed origins. Override the URL with a manifest override.

Documentation: [/failure-handling#manifest-loading](/docs/failure-handling#manifest-loading). Diagnostic URL: `https://platform.docs.local/docs/failure-handling#manifest-loading`.

### MANIFEST_INVALID

Rebuild the remote with a compatible @platform/vite; run `platform validate` in the remote project.

Documentation: [/manifests#validation](/docs/manifests#validation). Diagnostic URL: `https://platform.docs.local/docs/manifests#validation`.

### MANIFEST_ORIGIN_DENIED

Add the origin to `allowedOrigins` in the host configuration or use a same-origin manifest URL.

Documentation: [/manifest-overrides#origin-validation](/docs/manifest-overrides#origin-validation). Diagnostic URL: `https://platform.docs.local/docs/manifest-overrides#origin-validation`.

### PROTOCOL_INCOMPATIBLE

Upgrade the remote's @platform/react and @platform/vite, or the host's @platform/host, so the protocol majors match.

Documentation: [/module-federation#protocol-compatibility](/docs/module-federation#protocol-compatibility). Diagnostic URL: `https://platform.docs.local/docs/module-federation#protocol-compatibility`.

### REMOTE_LOAD_FAILED

Check that the remote entry is reachable and served with CORS headers; the host retries with cache busting.

Documentation: [/failure-handling#remote-loading](/docs/failure-handling#remote-loading). Diagnostic URL: `https://platform.docs.local/docs/failure-handling#remote-loading`.

### REMOTE_DISABLED

Enable the MFE in the runtime configuration (`mfes.<mfeId>.enabled`).

Documentation: [/runtime-configuration#per-mfe-enablement](/docs/runtime-configuration#per-mfe-enablement). Diagnostic URL: `https://platform.docs.local/docs/runtime-configuration#per-mfe-enablement`.

### REMOTE_UNKNOWN

Register the MFE in the host registry or the runtime configuration.

Documentation: [/manifest-overrides#registry](/docs/manifest-overrides#registry). Diagnostic URL: `https://platform.docs.local/docs/manifest-overrides#registry`.

### DEPENDENCY_INCOMPATIBLE

The remote bundles its own copy; check the shared dependency diagnostics and the `shared` overrides in mfe.config.ts.

Documentation: [/dependency-sharing#incompatible-fallback](/docs/dependency-sharing#incompatible-fallback). Diagnostic URL: `https://platform.docs.local/docs/dependency-sharing#incompatible-fallback`.

### MOUNT_FAILED

The remote threw while mounting; see the remote's error boundary and telemetry.

Documentation: [/failure-handling#mounting](/docs/failure-handling#mounting). Diagnostic URL: `https://platform.docs.local/docs/failure-handling#mounting`.

### WIDGET_UNKNOWN

Export the widget from `createMfe({ widgets })` and rebuild the remote.

Documentation: [/widgets#registration](/docs/widgets#registration). Diagnostic URL: `https://platform.docs.local/docs/widgets#registration`.

### WIDGET_MOUNT_FAILED

The widget threw while mounting; other widgets keep running.

Documentation: [/widgets#failure-isolation](/docs/widgets#failure-isolation). Diagnostic URL: `https://platform.docs.local/docs/widgets#failure-isolation`.

### PERMISSION_DENIED

The current user lacks a permission group the manifest requires; backend authorization still applies.

Documentation: [/permission-groups#preflight](/docs/permission-groups#preflight). Diagnostic URL: `https://platform.docs.local/docs/permission-groups#preflight`.

### CAPABILITY_UNAVAILABLE

The host does not approve this capability; feature-detect with `usePlatform((p) => p.capabilities)`.

Documentation: [/platform-context#capabilities](/docs/platform-context#capabilities). Diagnostic URL: `https://platform.docs.local/docs/platform-context#capabilities`.

### SHORTCUT_CONFLICT

Choose another shortcut; the second registration is rejected, the first one keeps the shortcut.

Documentation: [/commands#shortcut-conflicts](/docs/commands#shortcut-conflicts). Diagnostic URL: `https://platform.docs.local/docs/commands#shortcut-conflicts`.

### COMMAND_INVALID

Command ids are local, kebab-case and unique within the MFE.

Documentation: [/commands#definition](/docs/commands#definition). Diagnostic URL: `https://platform.docs.local/docs/commands#definition`.

### COMMAND_FAILED

The handler threw or rejected; the palette shows the error and the shell keeps running.

Documentation: [/commands#failure-states](/docs/commands#failure-states). Diagnostic URL: `https://platform.docs.local/docs/commands#failure-states`.

### SETTINGS_INVALID

Every field needs `defaultValue`; keys are unique within the group.

Documentation: [/settings#definition](/docs/settings#definition). Diagnostic URL: `https://platform.docs.local/docs/settings#definition`.

### SETTINGS_VALUE_INVALID

The stored value failed the schema and no migration fixed it; the field was reset to its default.

Documentation: [/settings#invalid-stored-values](/docs/settings#invalid-stored-values). Diagnostic URL: `https://platform.docs.local/docs/settings#invalid-stored-values`.

### STORAGE_INVALID

The stored value failed the schema and no migration fixed it; defaults were applied.

Documentation: [/storage#malformed-data](/docs/storage#malformed-data). Diagnostic URL: `https://platform.docs.local/docs/storage#malformed-data`.

### STORAGE_UNAVAILABLE

Browser storage is blocked; the store falls back to memory for this session.

Documentation: [/storage#unavailable](/docs/storage#unavailable). Diagnostic URL: `https://platform.docs.local/docs/storage#unavailable`.

### RUNTIME_CONFIG_INVALID

Fix the runtime configuration document before the platform starts; the entrypoint validates it.

Documentation: [/runtime-configuration#validation](/docs/runtime-configuration#validation). Diagnostic URL: `https://platform.docs.local/docs/runtime-configuration#validation`.

### RUNTIME_CONFIG_FETCH_FAILED

Serve `/platform-config.json` from the same origin or inline it in the SSR document.

Documentation: [/runtime-configuration#loading](/docs/runtime-configuration#loading). Diagnostic URL: `https://platform.docs.local/docs/runtime-configuration#loading`.

### ROUTE_PREFIX_INVALID

Route prefixes start with `/`, contain only lowercase segments and have no trailing slash.

Documentation: [/route-prefixes](/docs/route-prefixes). Diagnostic URL: `https://platform.docs.local/docs/route-prefixes`.

### MFE_ID_INVALID

`mfeId` is kebab-case (`asset-tracker`); it is inferred from the package name and persisted in `.platform/identity.json`.

Documentation: [/manifests#mfe-id](/docs/manifests#mfe-id). Diagnostic URL: `https://platform.docs.local/docs/manifests#mfe-id`.

### DEV_RESTART_REQUIRED

Restart the development server: manifests, shared dependency versions, federation configuration and generated route trees are read at startup.

Documentation: [/local-development#restart-diagnostics](/docs/local-development#restart-diagnostics). Diagnostic URL: `https://platform.docs.local/docs/local-development#restart-diagnostics`.

### TELEMETRY_FAILED

The telemetry adapter threw; events are dropped and the MFE keeps running.

Documentation: [/telemetry#failure-isolation](/docs/telemetry#failure-isolation). Diagnostic URL: `https://platform.docs.local/docs/telemetry#failure-isolation`.

### DEVTOOLS_UNAVAILABLE

Enable `platform:devtools` in localStorage and check the host devtools policy.

Documentation: [/developer-tools#enabling](/docs/developer-tools#enabling). Diagnostic URL: `https://platform.docs.local/docs/developer-tools#enabling`.

### OVERLAY_FAILED

The overlay root could not be created; overlays fall back to document.body.

Documentation: [/overlays](/docs/overlays). Diagnostic URL: `https://platform.docs.local/docs/overlays`.

### INTERNAL

Unexpected failure; the diagnostic carries the original error.

Documentation: [/troubleshooting](/docs/troubleshooting). Diagnostic URL: `https://platform.docs.local/docs/troubleshooting`.
